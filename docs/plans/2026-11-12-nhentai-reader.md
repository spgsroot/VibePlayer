# Ридер nhentai

Дата: 2026-11-12. Источник API: [nhentai API v2](https://nhentai.net/api/v2/docs).

## Что сделано

Ридер открывается с плеера, маршрут `manga` и `manga/{id}`.

- Поиск и карточка идут в `https://nhentai.net/api/v2`.
- Ключ вшит в `NhentaiSecrets` и уходит только заголовком `Authorization: Key …`. В URL его нет.
- Картинки берутся с зафиксированных хостов `https://i1.nhentai.net` и `https://t1.nhentai.net`. Путь страницы не переписывается.
- Избранное хранится в Room (`library_galleries`, миграция 4→5) и синхронизируется `POST`/`DELETE /galleries/{id}/favorite`.
- «В библиотеку» скачивает страницы в `files/manga/{id}/`. Ридер открывает локальный файл, если он уже есть.
- Перелистывание шлёт короткий импульс в `CommandSender` только на аудио-актуаторы. Сила задаётся слайдером в ридере.
- `files/manga/` исключён из backup и device transfer.

Ключ проверен запросом галереи 1: ответ 200, 14 страниц, миниатюра `galleries/9/thumb.jpg`.

## Не входит

Комментарии, zip-архив, ввод ключа пользователем, запрос списка CDN при каждом открытии.
